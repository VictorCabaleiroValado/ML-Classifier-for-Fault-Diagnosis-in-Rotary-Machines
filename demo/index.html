    How reliable is this result?

    EXPLORATORY HOLDOUT EVALUATION

    — category accuracy

    Evaluation loads with the model.

    The model was trained on 80% of the rows; the remaining 20% were held out, stratified by category, with seed 42. Every displayed example comes from the held-out set.

    Related acquisitions may occur in both partitions, so the score does not establish performance on independent machines. Source labels come from filenames. A disagreement does not prove the label is wrong.

    No calibrated confidence, fault severity, remaining-life prediction or maintenance recommendation is provided. Historical 50/75 RPM data lack the original measurements needed for independent verification.

    About the data and the Python project

    The Python workflow connects vibration measurements, time-domain and FFT features, supervised learning and evaluation. This browser demo uses the time-domain decision tree.

    The chart retains min/max points from 240 bins. Connecting lines do not reconstruct the full waveform. Sample indices and original sensor values are shown; sampling rate and physical units are not assumed. FFT is not computed from reduced display points.

    B1 / B2 identify the two bearings; X, Y and Z are their recorded axes. Motor, Gearbox and Tachometer complete the nine channels.
